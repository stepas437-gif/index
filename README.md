# CHUPEP

Платформа для загрузки музыкальных треков и их оценки стримером.

## Локальный запуск

```powershell
npm install
node server.js
```

Откройте <http://localhost:3000>. Для локального режима параметры находятся в `.env`.

## Публикация на VPS

Приложение использует SQLite и хранит загруженные MP3/обложки на диске, поэтому на VPS нужно сохранять каталог данных между перезапусками. В репозиторий не попадают `.env`, `music.db` и содержимое `uploads`.

1. Установите на VPS Node.js LTS, Git, Nginx и PM2.
2. Скопируйте код в каталог приложения и выполните `npm ci --omit=dev`.
3. Создайте `/var/lib/chupep` и каталог `/var/lib/chupep/uploads`, затем назначьте владельцем пользователя, под которым запускается PM2.
4. Создайте `.env` на основе `.env.example`. Обязательно укажите настоящий HTTPS-адрес, пароль стримера длиной от 12 символов и рабочие SMTP-параметры.
5. Если нужно перенести текущие данные, отдельно скопируйте локальные `music.db` и `uploads` в `/var/lib/chupep/`. Не загружайте их в GitHub.
6. Запустите приложение:

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

7. Скопируйте `nginx/chupep.conf.example` в конфигурацию Nginx, замените домен и включите сайт. После этого получите HTTPS-сертификат через Certbot и перезапустите Nginx.
8. Проверьте `https://ваш-домен/healthz`: ответ должен быть `{"status":"ok"}`.

После изменения кода:

```bash
git pull
npm ci --omit=dev
pm2 restart chupep --update-env
```

## Первый запуск

Войдите под `STREAMER_EMAIL` и `STREAMER_PASSWORD`. Пользователи смогут зарегистрироваться, подтвердить email и загрузить трек. Стример оценивает треки на странице администратора.

## Резервные копии

Регулярно копируйте `/var/lib/chupep/music.db` и `/var/lib/chupep/uploads` на отдельный диск или в объектное хранилище. Одного GitHub-репозитория для резервной копии пользовательских данных недостаточно.
